## Example A — BTC 12H (`btc-12h-long-setup.webp`)

**Regime call: Trend (bull) · pullback into value / discount**

| Dump rule | What the chart shows |
|-----------|----------------------|
| Trend = HH/HL + above 55/200 | Higher-low structure from the Aug–Sep advance; ascending trendline under the pullbacks. Pullback is a pause inside the bull story, not a new bear regime. |
| Range / value = VAL / profile work | Fixed-range volume profile on the impulse; yellow mark on the high-volume band ~83k–87k. Price left that node and is probing lower into discount. |
| Don’t trade the middle | Plan is not mid-chop for sport — entry thesis sits in the **gray demand / Fib discount cluster** (~0.618–0.786, entry marked ~81,288), not floating mid-range. |
| Buyers vs sellers | Sellers pressed the pullback; the long box assumes buyers defend the discount zone. Invalidation is explicit under that defense (SL ~79,888). |
| Thought-out plan | Entry / stop / target marked (target ~87,700 prior supply). *You can't regret a well thought out plan.* |

**Trade / wait / skip (structure only):**  
Context says **with-trend long idea only if value/discount is defended**. Until 15m shows the reclaim / trigger you teach in Course 03, this is a **wait for execution** — not a mid-air chase at ~82.3k if that’s still “middle” relative to your zone.

**Transition check:** No clean “sweep critical level → close back inside + volume/RSI” marked here. Don’t force the transition label; this is a **trend pullback into value**.

## Example C — NEAR 6H (`near-6h-sweep-reclaim.png`)

**Regime call: Transition — sweep of a critical level, then reclaim**

| Dump rule | What the chart shows |
|-----------|----------------------|
| Critical level | Horizontal ~**4.60** — prior defense marked with the two **X**s (held twice before the break). |
| Sweep | Sharp break under 4.60 (yellow **U** scoop) — liquidity run / failed breakdown attempt. |
| Clear close back inside | Price returns and holds back **above** 4.60; last print on the shot ~**4.776**. |
| Don’t rush | On *this* frame the reclaim is visible — but your rule still wants **multiple candle closes** + **BTC / cross-asset** before you treat it as done. One reclaim candle ≠ full permission. |
| Buyers vs sellers | Sellers got the break; buyers answered under the level and pulled price back into the prior range. The level is where the fight is — not a random line. |

**What this is not:** A clean new bear trend. Structure broke *and came back*. That’s your transition / failed-break language from lesson 1.4.

**Trade / wait / skip (structure only):**  
After the scoop: **wait** until multi-close acceptance above 4.60 *and* BTC isn’t dumping the idea. Then Course 03 owns the trigger. Chasing the first wick back through 4.60 is the rush you refuse.

**Stack note:** 6H is your other context clock. Same dump stack as BTC’s 12H — regime here, execution on 15m.
