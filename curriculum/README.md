# TraderSveezy Playbook — curriculum

Written playbook first. Video later if we want it.

## How we work

1. You dump messy notes (voice memo transcript, bullets, “I usually…” rules).
2. We turn that into lessons, worksheets, and site copy in your voice.
3. You correct anything that isn’t how you actually trade.
4. We ship modules as they’re solid — not when all five courses are filmed.
