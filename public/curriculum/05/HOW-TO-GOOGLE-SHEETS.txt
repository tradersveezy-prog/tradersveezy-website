TraderSveezy - Course 05 desk files
===================================

1. Download the CSV from the course.
2. Google Sheets -> Blank spreadsheet.
3. File -> Import -> Upload -> pick the CSV.
4. Choose "Insert new sheet(s)" so every file lands in one workbook.
5. Name the tabs: Checklist / Log / Losses / Weekly / Rules.

Extras
------
- View -> Freeze -> 1 row
- Yes/No columns: Data -> Data validation -> Dropdown
- Duplicate a blank log row when you need more space
